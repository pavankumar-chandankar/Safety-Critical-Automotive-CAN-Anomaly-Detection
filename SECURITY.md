# Security disclosure and scope

The project is an offline research tool and does not provide vehicle control. Report parser crashes, unsafe memory behavior, unauthorized network I/O, supply-chain vulnerabilities and report data exposure privately to the repository maintainer. Include a minimal synthetic reproducer and toolchain versions; do not post sensitive real vehicle traces or proprietary DBC files in public GitHub issues.

The seeded source files in `defects/seeded/` are intentionally unsafe **demonstrations** and excluded from release binaries. Their warnings are expected, not production defect evidence. No automotive safety/security certification is claimed.
