# Historical files and source provenance

Before this rebuild the repository contained exploratory Python snippets about unrelated public-transport demand forecasting and a car-evaluation dataset, plus a minimal C++ CAN CSV validator. These are **not** represented as the new CAN Sentinel implementation.

The original state is preserved by an explicit GitHub backup branch, and historical files remain accessible through Git history. On GitHub the prior source files are migrated into this directory without rewriting their contents. The downloadable engineering ZIP focuses on the new working C++17 platform; the exact historical blobs are available from the repository and its backup branch.
